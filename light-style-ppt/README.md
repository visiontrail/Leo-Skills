# light-style-ppt Skill - Backup & Open Source

此文件夹包含 `light-style-ppt.skill` 的完整解压内容，用于备份和开源目的。

## 文件夹结构

```
light-style-ppt-backup/
├── SKILL.md                          # Skill 元数据和文档
├── references/
│   └── design-tokens.md              # 设计系统规范（颜色、排版、间距）
└── scripts/
    └── helpers.js                    # 辅助函数库
```

## Skill 描述

**light-style-ppt** - 使用温暖的编辑设计风格创建精美的 .pptx 演示文稿

- 支持浅色和深色幻灯片主题
- 羊皮纸色调 + 赤陶色重音
- Serif/Sans 排版层级
- 杂志级设计布局

## 使用场景

- 创建演示文稿 / 幻灯片组
- 制作投资者展示
- 生成报告展示
- 会议准备材料

## 关键特性

✨ **两种环境设计**
- 浅色幻灯片：羊皮纸背景 + 黑色文本
- 深色幻灯片：纯黑背景 + 银色文本

📐 **完整的设计系统**
- 精确的颜色定义
- 排版规范
- 间距指南

🔧 **可复用的辅助函数**
- `scripts/helpers.js` 包含 pptxgenjs 集成工具
